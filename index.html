Microsoft Excel – Introducere

Ce este Excel?

Microsoft Excel este un program de calcul tabelar, creat de Microsoft și inclus în pachetul Microsoft Office. Cu el organizăm datele în tabele, calculăm cu formule și funcții și reprezentăm datele prin diagrame.

Caracteristici Excel

  1. 1Lucrează cu registre (fișiere .xlsx) formate din mai multe foi de calcul.
  2. 2Face calcule cu formule și funcții gata făcute.
  3. 3Recalculează automat rezultatele când se schimbă datele.
  4. 4Permite sortarea și filtrarea datelor.
  5. 5Transformă tabelele în diagrame ușor de citit.
  6. 6Evidențiază valorile importante prin formatare condiționată.

Termeni importanți

Registru
fișierul Excel (.xlsx)
Foaie de calcul
o pagină a registrului, cu rânduri și coloane
Celulă
locul unde se întâlnesc o coloană și un rând
Adresă
numele celulei, de exemplu B3
Zonă de celule
un grup de celule, de exemplu A1:C5
Formulă
un calcul care începe cu semnul =
Funcție
formulă gata făcută: sumă, medie, maxim
Diagramă
reprezentarea grafică a datelor

La ce folosim Excel?

  1. 1Cataloage cu note și medii.
  2. 2Bugetul personal sau al familiei.
  3. 3Evidența cheltuielilor și a vânzărilor.
  4. 4Liste de prețuri și facturi.
  5. 5Orare și planificări.
  6. 6Analiza datelor cu tabele și diagrame.

Calculează, analizează și transformă datele în idei cu Excel! ★
